# Starbucks Website Clone

## Overview
A static clone of the Starbucks website created to practice HTML, CSS, and JavaScript skills. This project replicates the homepage and main visual elements of the Starbucks website.

## Features
- Navigation bar with hover effects.
- High-quality images and styles similar to the original Starbucks website.
- Static content designed to replicate the Starbucks homepage.

## Technologies Used
- **HTML5**: For the structure.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactive elements.
